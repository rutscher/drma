# 🚴 GRVL DRMA 🚴

## The Most Absurdly Over-Engineered Gravel Bike Race Website Ever Created

Welcome to GRVL DRMA - a parody website that asks the question: "What if we took a simple gravel bike race website and made it completely, unnecessarily, ridiculously over-engineered?"

- **5 Theme Modes**: Gold, Silver, Platinum, Diamond, and RGB Gaming Mode

### 🛠️ Tech Stack

- **Frontend**: Vanilla JavaScript (because we hate ourselves)
- **Styling**: Pure CSS3 with 1000+ lines of animations
- **Backend**: None (it's just a static site, we're not THAT crazy)
- **Deployment**: Docker + nginx
- **Over-Engineering Level**: 11/10

### 🚀 Quick Start

#### Option 1: Docker Compose (Recommended)

```bash
docker-compose up --build
```

Then visit `http://localhost:8080` and prepare for visual assault.

#### Option 2: Docker

```bash
docker build -t grvl-drma .
docker run -p 8080:80 grvl-drma
```

#### Option 3: Local Development

Just open `index.html` in your browser. That's it. No build process. No npm. Pure chaos.
